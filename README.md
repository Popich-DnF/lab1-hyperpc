# Лабораторная работа 1 — HYPERPC

Учебная одностраничная вёрстка по мотивам сайта [HYPERPC](https://hyperpc.ru). Не является официальным сайтом компании.

## Что выполнено

**Задание 1.1 (HTML)**
- изображение: `img/hero-pc.svg`, логотип;
- нумерованный список «Этапы заказа» и список контактов;
- ссылки трёх типов: внешний сайт, `mailto:`, `tel:`;
- таблица «Модели и цены»: 6 строк × 4 столбца;
- три секции `<section>` (О компании, Модели и цены, Контакты) и навигация по якорям в шапке.

**Задание 1.2 (CSS)**
- все стили в `css/style.css`, подключены через `<link>`, в HTML нет `style` и `<style>`;
- тёмная тема с хорошим контрастом, читаемый размер шрифта и отступы;
- заливка нечётных строк таблицы через `:nth-child(odd)`;
- адаптивность от 340 px через `@media`.

## Запуск

Откройте `index.html` в браузере.
